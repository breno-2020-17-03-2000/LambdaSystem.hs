LambdaSystem.hs — Gestão Funcional de Projetos e Pessoas

Este projeto em Haskell nasce da ideia de unir elegância funcional com um sistema prático de RH. Ele permite cadastrar, buscar e promover funcionários,
calcular salários e gerenciar projetos com orçamentos e equipes. Tudo gravado em arquivos locais .dat e exportável em JSON. A lógica é enxuta, 
mas poderosa — usando monads, pattern matching e type classes para um fluxo claro. Ideal para quem valoriza código limpo e propósito.
Não é apenas um CRUD: é uma pequena arquitetura feita com intenção.
